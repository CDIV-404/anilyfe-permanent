# Anilyfe anime-futuristic interface direction

The permanent Anilyfe storefront will shift from soft editorial pastels into a dark, high-contrast anime-tech marketplace. The experience is built around a deep ink-blue background, ultraviolet surfaces, cyan interface lines, magenta energy accents, and restrained gold highlights for rare collectible states. Content remains readable and spacious rather than noisy.

| Layer | Direction |
|---|---|
| Background | Midnight navy, radial nebula glows, fine HUD grid, drifting particle field, and low-opacity scan lines. |
| Typography | `Orbitron` for navigation, numeric system labels, and buttons; `Space Grotesk` for readable body text; a compact serif only for a restrained collector-story accent. |
| Interface | Thin cyan outlines, frosted navy panels, angled corner brackets, glowing status dots, and clearly separated data blocks. |
| Motion | Short transform/opacity transitions, ambient glow drift, subtle holographic card parallax, and a Three.js model stage. Motion pauses under `prefers-reduced-motion`. |
| 3D stage | A dark holodeck with colored rim lights, a rotating GLB collectible, clear drag/zoom hints, and category chips that switch models. |
| Accessibility | High-contrast text, semantic headings, visible focus rings, keyboard-reachable collection controls, and optional non-animated behavior. |

The homepage will use the recurring **portal-grid** motif: a thin segmented frame around the hero, cards, and 3D panel that suggests a gateway into each fandom world without overwhelming the shopping experience.
